# 대학 등록금 한눈에 — React 대시보드

2025년과 2026년 일반대학교 등록금 데이터를 학생 관점에서 검색·비교하는 React + TypeScript 웹 대시보드입니다.

## 포함 기능

- 일반대학교만 분석
- 본교·분교·제2캠퍼스를 독립 단위로 표시
- 등록금 0원 제외
- 2025년·2026년 전년 비교
- 핵심 KPI 및 등록금 구간 시각화
- 지역·설립구분·변동 상태·금액 필터
- 대학명 검색 및 상세 모달
- 최대 5개 대학 비교
- 지역별·계열별 분석
- 필터 결과 CSV 다운로드
- 반응형 모바일 UI
- 데이터 기준 및 분석 한계 안내

## 실행 방법

Node.js가 설치된 환경에서 다음 명령을 실행하세요.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

## 프로덕션 빌드

```bash
npm run build
npm run preview
```

## 데이터

전처리된 데이터는 다음 파일에 포함되어 있습니다.

```text
public/data/tuition-data.json
```

분석 기준:

- 학교종류가 `대학교`인 데이터만 사용
- 등록금이 0원인 행 제외
- 캠퍼스·분교 독립 처리
- 동일 학교·캠퍼스 명칭 기준 연도 비교
- 계열별 0원은 `null`로 변환
- 대학·캠퍼스별 단순평균

## 주요 파일

```text
src/App.tsx       전체 화면 및 기능
src/styles.css    반응형 디자인
src/types.ts      TypeScript 데이터 타입
src/utils.ts      필터·금액 표시·CSV 유틸리티
```

## 참고

`package.json`은 패키지 버전을 `latest`로 지정했습니다. 실제 운영 배포 시 `npm install` 후 생성되는 lock 파일을 저장소에 커밋해 버전을 고정하는 것을 권장합니다.
